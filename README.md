# 🚀 Karatsuba
> Projeto da disciplina de [Programação Estruturada (P2)](https://github.com/Dudubraga/Estruturas-de-Dados)

## 📖 Visão Geral

Implementar o algoritmo de Karatsuba em C, uma técnica de multiplicação rápida e eficiente para números enormes usando uma abordagem recursiva de dividir e conquistar. O programa recebe dois números inteiros de até 32.768 dígitos como entrada e retorna o produto exato entre eles.

- **Instituição:** UNICAP
- **Professor:** Diego Pinheiro
- **Período:** 2023.2

## ✨ Funcionalidades

- Multiplicação de grandes números que excedem a capacidade dos tipos de dados padrão.
- Aritmética com strings.
- Normalização de tamanho de strings.
- Manipulação de substrings.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C
